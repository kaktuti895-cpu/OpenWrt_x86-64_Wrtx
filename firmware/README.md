# Firmware build records

Use this directory for small text records describing firmware builds, not for committing large binary images.

Each build record should include:
- OpenWrt version and source revision.
- Target and subtarget.
- Device/profile, if applicable.
- Package selection and configuration revision.
- Build date and build environment.
- Image filenames, sizes, and SHA-256 checksums.
- Known limitations and installation notes.

Publish large images through GitHub Releases or suitable external storage when appropriate.
